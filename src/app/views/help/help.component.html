Domainwechsel – Daten migrieren

Da alle Daten lokal im Browser gespeichert sind (IndexedDB), sind sie an die jeweilige Domain gebunden. Beim Wechsel von localhost auf easy-bill.oe-home.de müssen die Daten manuell übertragen werden.

1

Backend-Server starten (auf dem lokalen Rechner)

Der Export-Vorgang benötigt den laufenden Backend-Server. Stelle sicher, dass der Server auf Port 4000 läuft, bevor du exportierst.

2

Aufträge exportieren

Öffne auf localhost die Seite Aufträge und klicke auf den -Button (Export). Die Datei wird auf dem Server gespeichert unter:

[FILE_SAVE_LOCATION]/backup_orders/orders_backup.json
3

Kunden exportieren

Öffne die Seite Kunden und klicke auf den Export-Button. Die Datei wird gespeichert unter:

[FILE_SAVE_LOCATION]/backup_customer/customer_backup.json
4

Backup-Dateien bereithalten

Kopiere die beiden JSON-Dateien auf deinen Computer (z.B. Desktop), damit du sie im nächsten Schritt hochladen kannst.

5

Aufträge auf neuer Domain importieren

Öffne auf easy-bill.oe-home.de die Seite Aufträge und klicke auf den -Button. Wähle die Datei orders_backup.json aus und bestätige mit Importieren.

6

Kunden auf neuer Domain importieren

Öffne die Seite Kunden und klicke auf den Import-Button. Wähle customer_backup.json aus.

7

Artikel importieren (optional)

Artikel können über die Seite Artikel per Excel-Import (.xlsx) neu angelegt werden. Es gibt keinen automatischen Backup-Export für Artikel.

Alle importierten Daten behalten ihre ursprünglichen IDs – Verknüpfungen zwischen Aufträgen und Kunden bleiben erhalten.

Datenquelle

Steuert, ob die Daten lokal im Browser (IndexedDB) oder im Backend (SQLite) gespeichert werden. Die Einstellung wird gespeichert und beim nächsten Laden angewendet – beim Umschalten wird die Seite automatisch neu geladen.
